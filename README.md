# VPNiz: versiones publicadas

Aquí solo se publican los instaladores de VPNiz. El código fuente es privado.

## Windows

1. Abre la [última versión](https://github.com/delayisus/vpniz-releases/releases/latest) y descarga **`VPNiz-win-Setup.exe`**.
2. Ábrelo. Windows puede avisar con «Windows protegió su PC», porque el instalador no tiene firma digital: pulsa **Más información** y luego **Ejecutar de todas formas**.
3. VPNiz se abre solo. La primera vez te pide instalar su parte de sistema: pulsa **Instalar** y acepta el permiso de Windows.

## Android

1. En el móvil, abre la [lista de versiones](https://github.com/delayisus/vpniz-releases/releases) y busca la más reciente que empiece por **«VPNiz Android»**. Descarga su archivo **`VPNiz-android-….apk`**.
2. Ábrelo. Android avisará de que viene de un origen desconocido: permítelo y pulsa **Instalar** (o **Instalar de todas formas**).
3. Abre VPNiz y añade tu servidor con **Escanear código QR**.

## Actualizar

No hace falta volver aquí. VPNiz avisa cuando hay una versión nueva, te cuenta qué cambia y se actualiza con un clic. Tus ajustes y tus servidores se conservan.
